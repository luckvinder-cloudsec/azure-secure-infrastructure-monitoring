# Azure Secure Infrastructure Monitoring

## About This Project

This project is designed to demonstrate practical Microsoft Azure cloud administration and security monitoring skills.

## Project Goals

- Deploy a secure Linux virtual machine.
- Configure Azure Virtual Network and Network Security Groups.
- Set up Azure Monitor and Log Analytics.
- Investigate Linux authentication events using KQL.
- Configure and test security alerts.

## Technologies

- Microsoft Azure
- Azure Virtual Machines
- Azure Networking
- Azure Monitor
- Log Analytics
- Kusto Query Language (KQL)

## Status

In Progress — implementation and testing are pending.

## Learning Outcome

Develop practical experience in Azure infrastructure security, centralized logging, threat detection and incident investigation.
